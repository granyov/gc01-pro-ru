# Начать работу

**v0.2.0 — experimental. Образ приложения собирается локально; USB-установщик не подтверждён.**

1. Сверьте маркировку платы GC01 V0.2 и MCU CH32F103R8T6.
2. Прочитайте [аппаратные ограничения](docs/HARDWARE.md).
3. Подготовьте проверяемую резервную копию и способ восстановления по [RECOVERY](RECOVERY.md).
4. Для разработки соберите исходники по [BUILD](docs/BUILD.md).
5. Перед записью выполните условия из [FLASH](FLASH.md). Не копируйте локальный app.bin на USB-диск.

Оригинальный файл владельца `GC-01_V1.6.bin` не включён в проект. По имени файла
нельзя определить адрес записи или наличие загрузчика. Для подтверждения USB-обновления
нужны сам файл (локально), его hash/векторная таблица и сверка с резервной копией прибора.
