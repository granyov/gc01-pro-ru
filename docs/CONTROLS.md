# Управление

| Действие | Клавиша |
|---|---|
| Измерение / среднее / доза / график | ↑ / ↓ |
| Дополнительное поле измерения или масштаб истории | ← |
| Настройки / выбрать | → |
| Назад из меню | ← |
| Включение / выключение | удерживать OK |
| Погасить экран измерения | короткое OK |
| Блокировка | удерживать ← + OK |
| Звук импульсов | удерживать → на измерительном экране |
| Сброс текущего измерения / подтверждение тревоги | удерживать ← |
| Восстановительный старт настроек | ↑ + ↓ при запуске приложения |

В настройках добавлены **Сеанс** и **Журнал**. Журнал листается ↑/↓ по пять строк;
самые новые события сверху. Время в журнале — UTC из RTC (часы в основном заголовке
показываются с выбранным часовым поясом). R — мощность, D — накопленная доза,
F — ошибка трубки; 0 — нет, 1 — предупреждение, 2 — тревога. Переход обратно к нулю
тоже записывается. Это RAM-журнал, исчезающий после перезапуска, максимум 16 записей.

«Статистика» upstream — диагностика трубки: её время работы, число импульсов,
мёртвое время, ID устройства и напряжение батареи. Тип MCU фиксирован target-сборкой
и возвращается в идентификаторе USB.

В «Измерения» задаются единицы, усреднение и вторичные единицы. CPM и CPS показываются
как «имп/мин» и «имп/с». На основном экране выбранное дополнительное поле меняется ←;
CPM, CPS, доза и график не помещены одновременно в одну область 320×240.

История: 10 минут, 1 час, 1 день, 1 неделя, 1 месяц и 1 год. Реальная глубина ограничена
Flash и интервалом записи. Отдельных масштабов 1/5/15 минут в этой версии нет.
Экспорт USB использует существующий протокол Rad Pro; инструменты и команды:
[reference manual upstream](https://github.com/Gissio/radpro/blob/c7454800ab5e4008a6258369e164b25c5fa3045c/docs/reference-manual.md).
Совместимость ПК-клиентов с изменённым именем устройства ещё требует проверки.
