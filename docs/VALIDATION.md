# Проверка v0.2.0

Владелец сообщил, что предоставленная ему сборка v0.1.0 запустилась на GC01 V0.2.
Это подтверждает только факт запуска на одном экземпляре; способ записи, стабильность,
точность измерений и все функции им пока не описаны. v0.2.0 после изменения UI
ещё не запускалась на приборе.

v0.2.0 локально собрана ARM GCC 12.3.1: raw app **44352 байта** из 45052,
CRC-образ **45056 байт**, статическое ОЗУ **11920 байт**. Шесть экранов
просмотрены через C-рендерер, тесты логики и формата образа прошли.
Следующий аппаратный шаг — проверить читаемость консольного экрана, меню,
предупреждение/тревогу и read-back без изменения bootloader.

## Архив проверки v0.1.0

## Выполнено локально

* ARM GCC 12.3.1, PlatformIO 6.1.18, macOS arm64: успешная сборка.
* Линкер ограничивает приложение реальной картой 64 КБ CH32.
* ELF32 ARM little-endian, векторная таблица по `0x08004000`, начальный SP в 20 КБ RAM.
* Thumb reset/IRQ адреса указывают внутрь приложения; сегменты ELF совпадают с raw bin.
* Приложение: **44720 байт**. Образ с padding и CRC: **45056 байт**.
* До CRC осталось **332 байта**. Размер PlatformIO 44436 не включает все зазоры raw-образа;
  окончательным ограничителем является linker + проверка `.bin`.
* Статическая RAM: **11920 байт**. С зарезервированными heap/stack и выравниванием:
  **13464 байта**, из 20480. Это не измерение максимальной глубины стека.
* Host-тесты: эталон CRC32, 512 одиночных bit flips, границы Flash и переполнение адреса,
  min/max/avg-счётчики, кольцевой журнал и подавление повторов, граничные значения неопределённости.
* Python-тесты: CRC STM32, metadata/footer, неверный SP/target/vector, превышение размера,
  повреждение payload.
* UI отрисован реальным renderer-кодом на синтетических данных; проверены пять экранов.

Машиночитаемый результат: [build-report.json](build-report.json).
Точный результат GitHub CI показывается в Actions; workflow повторяет сборку начисто
и сравнивает image байт в байт. Тесты на ПК не исполняют все драйверы MCU.

## Не выполнено — блокирует публикацию бинарника

- [ ] Получить владельческий `GC-01_V1.6.bin` локально, hash и анализ векторов.
- [ ] Сверить фото GC01 V0.2 с распиновкой reference, кварц и модель трубки.
- [ ] Прочитать полный Flash и option bytes прибора, сверить два чтения.
- [ ] Проверить bootloader: вариант, перенос управления, формат USB install image, диапазоны стирания.
- [ ] Показать неизменность первых 16 КБ read-back после установки.
- [ ] Проверить LCD, клавиши, RTC, батарею, сон, звук, вибрацию и USB.
- [ ] Измерить HV и испытать счёт импульсов с известной частотой, включая насыщение.
- [ ] Проверить задержку тревог и статистику на низком фоне/ступени сигнала.
- [ ] Проверить стек под нагрузкой, работу USB при записи Flash и отсутствие потерь импульсов.
- [ ] Проверить CRC/bypass и отключение питания во время сохранения/стирания.
- [ ] Практически восстановить прибор из его резервной копии.

**Решение для v0.1.0: source-only prerelease.** Успешная сборка не означает,
что target и recovery path конкретного экземпляра уже проверены.
