# Аппаратная база и границы поддержки

Цель: **FNIRSI GC-01, маркировка платы GC01 V0.2, CH32F103R8T6**.
MCU подтверждён владельцем. Фото и его `GC-01_V1.6.bin` отсутствуют среди файлов
этой задачи: их содержимое не анализировалось. Нельзя считать одно имя V1.6
подтверждением MCU: в upstream есть V1.6 именно для APM32.

## Подтверждено исходниками, требует сверки на экземпляре

Reference: [Rad Pro, фиксированный commit](https://github.com/Gissio/radpro/tree/c7454800ab5e4008a6258369e164b25c5fa3045c).
Снимок имеет внутреннюю версию 3.1.2test2; проект не основан на объявленном стабильном релизе.
WCH описывает семейство CH32F103 как ARM Cortex-M3 с 64 КБ Flash и 20 КБ RAM:
[страница производителя](https://wch-ic.com/products/CH32F103.html),
[руководство оценки, раздел 3.3.2](https://www.wch.cn/uploads/file/20220519/1652940703139730.pdf).
Это **не CH32V103/RISC-V**. В CMSIS используется совместимый набор регистров STM32F103,
а `CH32` выбирает аппаратные особенности WCH. Строка STM32 в выводе PlatformIO —
имя CMSIS, не разрешение прошивать иной MCU.

| Параметр | Настройка reference |

| LCD | ST7789, 240×320, поворот 270° → 320×240 |

| LCD control | PC5 reset, PC9 CS, PC8 DC, PC7 WR, PC6 RD |

| Звук / вибрация | PA8 / PA9 |

Таблица перенесена из `firmware/src/stm32/gc01.h`, не восстановлена из недоступного фото.
Значения HV сохранены из reference; это параметры PWM, **не измеренное напряжение трубки**.
По умолчанию выбран профиль M4011 из Rad Pro. Реальную трубку и коэффициент необходимо
проверить: значение мощности дозы зависит от спектра излучения и калибровки.

## Карта Flash

| Диапазон включительно | Размер | Назначение |
|---|---:|---|
| `0x08000000–0x08003fff` | 16 КБ | Существующий загрузчик; не входит в сборку |
| `0x08004000–0x0800effb` | 45052 байта | Приложение; строгий предел линкера |
| `0x0800effc–0x0800efff` | 4 байта | CRC STM32 приложения |
| `0x0800f000–0x0800f3ff` | 1 КБ | Настройки и накопленные счётчики |
| `0x0800f400–0x0800ffff` | 3 КБ | Кольцевой журнал измерений |

Все записи/стирания прикладного Flash-драйвера ограничены последними четырьмя страницами.
Проверяются длина, переполнение и выравнивание; массового стирания нет.
Загрузчик может иметь собственную логику записи: защита приложения не доказывает
безопасность копирования файла на USB-диск.

## История и ОЗУ

В этой сборке журнал занимает **3 страницы**, а не 5 из примеров upstream.
При однобайтовых приращениях верхняя оценка — 3 × (1 + 1014) = **3045 записей**;
при двухбайтовых — **1524 записи**. Метки начала сеанса и крупные значения уменьшают ёмкость.
Длинный масштаб графика не означает, что Flash хранит год секундных измерений.

Журнал событий отдельно: 16 записей в RAM, очищается при перезапуске.
LCD использует небольшой текстовый буфер, не полный RGB565 framebuffer (он потребовал бы 153600 байт).
Графики, USB, стек прерываний и история делят 20 КБ RAM. Статический размер проверяется
сборкой; максимум использования стека под нагрузкой нужно измерить на приборе.
