# Запись прошивки: статус и процедура

## Текущий статус

**Автоматическая установка выключена.** В v0.1.0 есть исходники и локальный
экспериментальный образ приложения; совместимость с bootloader конкретного прибора
не подтверждена. Репозиторий и CI не публикуют `.bin`, `.elf` или установщик.

Локальный файл `build/experimental/*-app.bin` предназначен для проверки сборки:
начало `0x08004000`, размер `0xb000`, последние 4 байта — CRC STM32.
Это не полный дамп, не USB install image и не криптографически подписанный файл.
Сырой `firmware/.pio/build/gc01-pro-ru/firmware.bin` не имеет финального CRC.

## Условия перед аппаратной записью

* Подтверждены MCU, плата, кварц, LCD и распиновка.
* Сделаны и побайтно сверены два чтения всех 64 КБ Flash, сохранены SHA-256 и option bytes.
* Разобраны векторы bootloader и штатного образа; подтверждён переход на `0x08004000`.
* Известно, какие адреса стирает и пишет выбранный инструмент; bootloader сохраняется.
* Доступен SWD и проверено чтение прибора. Нет необходимости снимать защиту чтения.
* Пройдены тесты сборки и `tools/image.py`; питание устойчивое.

После этого разработчик может выполнить **секторную** запись проверенного app image
по `0x08004000`, затем read-back и сравнение всех записанных байтов, отдельно сравнить
`0x08000000–0x08003fff` с исходным дампом. Настройки `0x0800f000–0x0800ffff` в app image
не входят. Для неизвестной версии загрузчика команда записи здесь намеренно не приводится.

Не используйте PlatformIO Upload/Erase без проверки плана стирания. Разрешение сборки
не является разрешением полной очистки чипа.

## Штатное обновление через USB

[Rad Pro документирует USB-диск GC-01 и Windows 10/11](https://github.com/Gissio/radpro/blob/c7454800ab5e4008a6258369e164b25c5fa3045c/docs/devices/FNIRSI%20GC-01/install.md).
Он требует соответствующего **install.bin**, а не произвольного бинарника приложения.
В этой версии проекта такой пакет не создаётся: протокол, упаковка и загрузчик
экземпляра ещё не сверены. Инструкции upstream для другого файла не переносить вслепую.

Первый аппаратный запуск: тест кнопок/LCD/питания → HV → импульсы с известной частотой →
RTC/USB → тревоги → сохранение/восстановление. Результаты записать в `docs/VALIDATION.md`.
