# Резервная копия и восстановление

## До экспериментов

Сохраните владельческий оригинал отдельно от репозитория. Для анализа можно использовать
игнорируемый каталог `private/`; никогда не добавляйте файлы FNIRSI в коммит/релиз.
Файл обновления от производителя не обязательно содержит bootloader и option bytes.
Надёжная резервная копия — полный дамп **своего** MCU (64 КБ от `0x08000000`) плюс
зафиксированные option bytes и сведения о программаторе.

Через проверенный SWD-программатор прочитайте Flash дважды, сравните файлы и их SHA-256.
Не применяйте unlock/read-unprotect: снятие защиты может стереть Flash. Если чтение
запрещено, остановите процедуру и разберите защиту до любых операций записи.
Питание/распиновку сверяйте по плате; не соединяйте несколько источников 3.3 В.
Внутри имеется высоковольтная часть трубки.

[Аппаратный reference SWD от Rad Pro](https://github.com/Gissio/radpro/blob/c7454800ab5e4008a6258369e164b25c5fa3045c/docs/devices/FNIRSI%20GC-01/install-stlink.md)
показывает JP1. Это reference, а не подтверждение ориентации площадок на вашем фото.

## Если приложение запускается, но настройки мешают

Удерживайте **↑ + ↓ в момент запуска приложения**. Сохранённые настройки пропускаются,
сон экрана и логирование отключаются; используются заводские для проекта значения.
Отпустите клавиши после запуска. Валидные счётчики дозы не обнуляются этим действием.
Сохранение новых настроек возможно штатным путём; CRC не защищает от потери страницы
во время стирания, см. архитектуру.

## Если остался штатный USB-диск

На Windows 10/11, при выключенном приборе подключите USB data cable.
Upstream предлагает **→/Settings + OK/Power**, а также аппаратную кнопку reset около USB,
если диск не появился. Возврат штатного ПО возможен только файлом, проверенным для
этого MCU и этого загрузчика. `GC-01_V1.6.bin` по одному имени таким не считается.
Не копируйте экспериментальный `*-app.bin` как recovery firmware.

## Если USB-диска нет

Восстанавливайте через SWD из своего проверенного дампа с корректным начальным адресом.
Сначала попытайтесь подключение под reset, затем чтение/идентификацию. Не выполняйте
mass erase и не записывайте найденный в интернете bootloader. Если повреждён загрузчик,
полная запись собственного дампа допустима только после сверки MCU, адресов и питания;
после записи обязательны read-back и сравнение. При блокировке чтения не обещается
безусловное восстановление программным способом.

Проект не выполняет прошивку устройства и не меняет bootloader. Восстановление
конкретного экземпляра пока **не испытано**.
